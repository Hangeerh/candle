# Candle

Candle is a utility library for PyTorch.

Candle aims to provide helper functions/classes for common tasks
of various complexity, for example, batch renaming images or creating
datasets in WebDataset format.

# Building

Candle is currently in very early stage development.
Everything is subject to change.

You can build the python library by running:

```shelll
uv build
```

To use an editable install, run:

```shell
uv pip install -e .
```

This will install Candle in the local directory.
